# tpctl command catalog

The same list `tpctl commands` prints (generated from the parser there; this copy is for reading offline).

- **look**: `overview [--devices]` · `check` · `status` · `capabilities [--refresh]` · `settings [AREA…] [--all]` (any web-UI settings page, read-only; no AREA = list areas) · `settings set KEY on|off` (whitelisted switches: `settings set --list`)
- **mesh**: `mesh show [--sort tree|path|backhaul|health|devices]` (`health` = worst satellite overall: path + its devices) (ranked worst first, `rank=`, bottleneck `path_link=`, `ties=`) · `mesh node Q` · `mesh set Q [--name N] [--location L|none] [--led on|off] [--uplink auto|NODE]` (`--uplink` disruptive; only router-offered candidates, may be none → exit 8) · `mesh reboot Q` · `mesh wait`
- **devices**: `devices list [--node --band --weak --backhaul-limited --sort node|signal|weakest|name|rate|ip|band --reverse --limit --fields]` · `find Q [Q…]` (several in one read) · `identify [--ports] [--unknown]` · `probe Q [--no-ports]` (from this machine) · `rename Q NAME` (on the router) · `block Q` / `unblock Q` / `blocked` · `roaming [--since 1h] [--all]` · `leases` · `alias {set,rm,list}` (local-only; prefer `rename`)
- **wifi**: `wifi show` · `wifi set band B [--channel N] [--width W] [--txpower P]` (several settings, ONE restart) · `set smart-connect on|off [--ssid-2g/--ssid-5g/--ssid-6g NAME]` · `set ssid NAME [--band B]…` · `set txpower|channel|width … --band B` · `set ofdma-mimo all|ofdma_only|disable` · `wifi guest [on|off] [--ssid] [--password-stdin|--open]` · `wifi iot [on|off]` · `wifi schedule [on|off|add --from HH:MM --to HH:MM [--days] [--bands]|rm N]`
- **network**: `lan routes | route add NAME --to CIDR --via IP | route rm NAME | bindings | bind Q [--ip] | unbind IP` · `dhcp show | server on|off | set-range START END | set-gateway IP|router | set-lease MIN | set-dns PRIMARY [SECONDARY]|router | leases | reservations | reserve Q [--ip] | edit Q [--ip] [--on|--off] | unreserve Q` · `nat show | alg [k=v…] | upnp [on|off] | dmz on --to IP|off | triggers | trigger add NAME --on PORTS --open PORTS | trigger rm NAME | forwards | forward add NAME --to IP --port EXT[:INT] [--protocol] | forward rm NAME | ipv6-rules | ipv6-allow add NAME --to DEV|IPv6 --port P | ipv6-allow rm NAME` · `parental | add NAME --device Q [--bedtime HH:MM-HH:MM] | pause NAME on|off | rm NAME` · `qos show | set [on|off] [--down MBPS] [--up MBPS] | limits [--all] | limit Q [--down] [--up] | limit Q off`
- **system**: `system info` (incl. scheduled reboot) · `ports` · `log [--type T] [--level L] [--since 24h] [--grep TEXT] [--limit N] [--types]` · `firmware [--no-online]` · `led on|off` · `night-mode on|off [--from --to]` · `reboot-schedule on|off [--at --every --day]` · `time [--ntp S] [--timezone Z] [--24h|--12h] [--zones]` · `backup [--out PATH]` · `upgrade` · `auto-update on|off [--at H]` · `reboot`
- **diagnose**: `net ping [--device X] [--count N]` · `net diag HOST [--traceroute]` (from the router itself) · `net speed [--engine auto|cloudflare|apple|ookla|networkquality] [--connections N] [--no-upload]` (cloudflare = like speed.cloudflare.com, 1 connection; apple/ookla = 8 connections fill the line → honest `bufferbloat`; all direct, any OS; auto falls back to apple when Cloudflare rate-limits)
- **history**: `events [--since 6h|today] [--about X] [--what joined,left,moved,config,node] [--summary]` · `snapshot list | diff [SNAP [SNAP]] [--since] [--last-two] [--all] | timeline [--since] [--key] | save`
- **tools**: `api get EP [--op] | set EP k=v [--dry-run] [--partial] | endpoints [--grep X]` · `auth status [--check] | set-password | set-host URL|IP | login | logout` · `commands [--risk R]` · `schema` · `py -c CODE | py FILE | py - <<EOF`
- Every write takes `[--dry-run]`; disruptive ones (`wifi set/guest`, `mesh reboot/set --uplink`, `devices block`, `system reboot`) also need `[--yes]`.

Writes: plan → `--dry-run` (`would_change`) or no-op skip (`write status=skipped`; Wi-Fi radios untouched) → snapshot (`~/.local/state/tplink-router/snapshots/`) → write → re-read verify (`changed`/`unchanged`, or `mismatch` + exit 7).
